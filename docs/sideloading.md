# 安装与登录排查

DYYY 是加载到抖音中的插件。仓库提供插件源码和 `.deb` 打包配置，不提供抖音 IPA，也没有提供抖音 36.5.0 的下载地址。

README 标注仅在抖音 **36.5.0** 测试过。iOS 最低版本和编译架构是构建要求，不能据此判断任意设备都能加载插件。

## 选择安装方式

越狱包可从 [Releases](https://github.com/huami1314/DYYY/releases) 获取，或按 README 的[构建与打包](../README.md#构建与打包)生成 `packages/` 下的 `.deb`。

- 越狱设备：按设备环境选择 rootful、rootless 或 roothide 包。插件包需要安装到能够加载 Tweak 的环境中。
- 非越狱设备：需要另行准备可用的已解密抖音 IPA，注入插件后重新签名安装。开发者模式本身不提供 Tweak 注入能力。
- 标注“巨魔版”的 IPA：文件名不代表它能在其他系统或普通开发者签名下运行。需要分别确认安装方式、签名、抖音版本和插件兼容性。

如果 IPA 已经包含 DYYY，不要再次重复注入。整合包还可能包含其他插件；它们的行为不属于本仓库源码的验证范围。

## 安装后确认

1. 打开抖音，确认能够正常启动和加载内容。
2. 双指长按，或从抖音设置中的 DYYY 入口进入插件设置。
3. 分别验证登录和需要使用的插件功能。安装成功、进程启动、设置面板可打开，均不能代替登录和功能验证。

重新签名时，嵌套 Framework、动态库和扩展也需要有效签名。原应用的应用组、钥匙串、推送等权限未必能由新签名保留。重签和更新时应先确认包标识与应用标识权限，避免通过卸载重装误删已有数据。

## “应用版本过低”提示

如果提示包含“当前应用版本过低或经非官方渠道下载”，不要仅凭标题认定是本地版本号比较。应保留完整提示，确认它出现于启动、获取验证码还是提交验证码之后。

DYYY 的“屏蔽抖音检测更新”设置只拦截应用更新流程，不修改验证码登录请求或登录结果，不能作为登录失败的修复开关。

修改 `Info.plist` 的版本号也不会更新抖音程序、登录 SDK 或签名身份，不能保证解决该提示。排查时应分别记录：

- 抖音和 DYYY 的实际版本、IPA 来源及是否整合了其他插件。
- 设备系统、安装方式，以及是否重新签名或修改了包标识。
- 完整错误提示、发生步骤；如有诊断信息，只保留脱敏的错误域和错误码。

不要在 Issue、PR 或日志中提交手机号、验证码、密码、Cookie、会话令牌或完整登录请求与响应。后台账号检查的错误也不能直接当作本次验证码登录失败的原因。

可使用官方版验证同一账号能否登录，再区分账号问题与侧载包问题。更换实际抖音版本后，需要重新验证 DYYY；本仓库未承诺其他版本的兼容性。
